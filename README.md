# Tony — Single-Page Portfolio

A static portfolio sample featuring a personal introduction, about section, skills, services, work gallery, testimonials, blog previews, and contact information. It uses HTML, CSS, JavaScript, Bootstrap, jQuery, and Swiper assets.

## View the site

Open **`Index.html`** in a browser. Alternatively, use a local static server and visit `/Index.html`. No package manager or build step is required.

## Customize

- `Index.html` — sample identity, section content, links, and contact details.
- `css/style.css` and `css/zstyle.css` — page styles.
- `css/style.scss` — stylesheet source; no compiler script is supplied.
- `js/main.js` — custom interactions.
- Remaining CSS/JavaScript files — bundled libraries.

Replace the sample Tony Smith content and asset references before publishing. The repository contains no contact-message backend or CMS; displayed portfolio, blog, and contact content is static.

## Publish

Serve the repository as static files and preserve relative asset paths. The entry filename uses a capital I, so configure the host's default document or link explicitly to `Index.html` on case-sensitive systems.

There is no automated test suite. Review third-party/template asset licensing before reusing the included assets.
